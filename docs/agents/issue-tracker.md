# Issue tracker: None (local specs only)

This repo does not use an external issue tracker (`gh` and remote tracker CLIs are not used here).

## Conventions

- Architecture specs and phase runbooks live locally under `specs/` (for example `specs/implement.md` and `specs/<feature>/spec.md`).

## When a skill says "fetch the relevant ticket"

Read the local spec or runbook path referenced by the user under `specs/`. If no path was provided, check `specs/` or ask the user.

## When a skill says "publish to the issue tracker"

No issue tracker has been chosen for this repo yet. Do not create remote issues; ask the user where to write locally before creating any files.
